# 🌐 Premium Personal Portfolio

## 📖 Deskripsi Proyek
Repositori ini berisi *source code* dari situs *web* portofolio pribadi saya. *Website* ini dirancang kustom (tanpa CMS atau kerangka kerja frontend kelas berat) menggunakan prinsip desain modern *Glassmorphism* dan *Dark Theme* yang kuat, mencerminkan identitas saya sebagai pengembang *Hardware* dan *Software*.

Portofolio ini menonjolkan fluiditas antarmuka melalui kombinasi animasi pengguliran (*scroll reveal*) yang halus dan elemen partikel kanvas interaktif di latar belakang. Proyek ini mendukung struktur multi-bahasa (Indonesia dan Inggris) penuh serta bersifat responsif di berbagai perangkat genggam maupun desktop.

**Fitur Utama:**
*   **Glassmorphism UI:** Desain kartu proyek dan navigasi bergaya kaca buram premium.
*   **Interactive Particle Background:** Latar belakang *node* partikel bercahaya yang bereaksi terhadap kursor (*Particles.js*).
*   **Dynamic Project Filtering:** Sistem penyaringan portofolio instan untuk memisahkan karya IoT, Web, dan Rekayasa Energi.
*   **Scroll Animations:** Animasi pemunculan elemen terstruktur (*AOS Library*).
*   **Bilingual Support:** Sistem peralihan bahasa yang mulus (ID/EN).

## 🚀 Teknologi yang Digunakan
*   **Teknologi Web:** HTML5, CSS3, Vanilla JavaScript.
*   **Pustaka Pendukung:** AOS (Animate On Scroll), Particles.js, FontAwesome (Ikonografi).
*   **Desain:** Custom CSS Grid & Flexbox, CSS Backdrop-Filter.

## 📂 Struktur Direktori
*   `/css` - Berisi *file stylesheet* global dan kustomisasi animasi.
*   `/js` - Berisi logika Vanilla JS (Filter, Navigasi Mobile, Konfigurasi Partikel).
*   `/assets` - Berisi seluruh *resource* gambar proyek, logo, dan dokumen CV.
